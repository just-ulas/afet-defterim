## bu ne?

net kesildiğinde, enkazda, panikte telefonunda **işe yarayan** bir şey olsun diye yazıldı.

slogan değil. **dört düğme, offline not, acil kişi, düdük, ışık.**

yalan yok: 112’yi senin yerine aradığını iddia etmez. onay sende.

sol altta küçük **1881 — 193∞** — tıklanınca söz çıkar.

## enkaz modu

| | |
|--|--|
| 🆘 **YARDIM** | basılı tut → konum + sms + 112 (+ acil kişi) |
| 📍 **KONUM** | al · paylaş |
| 🔊 **SES** | düdük |
| 💡 **IŞIK** | flaş veya ekran |

**profil** → kan, not, acil kişiler · **araçlar** → mors, sinyal, nefes, artçı · **notlar** → offline rehber
